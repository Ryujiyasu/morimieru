# もりみえる (morimieru) — プロトタイプ

> 豊かな森を未来につなぐため、衛星の目で日本中の森を可視化し、
> その想いを支える会社と、森を守る人をつなぎます。

「企業 × 森林」を結び付ける営業ツール兼可視化プロトタイプ。
モリアゲ社の「一社一山」構想を技術的にバックアップする実装デモ。

## 構成

```
morimieru/
├── index.html                # メイン画面（4ステップフロー）
├── style.css                 # デザインシステム
├── app.js                    # フロー制御
├── data/
│   └── candidates.js         # モック候補森林データ
├── assets/                   # （画像生成後に配置）
├── certs/                    # （証明書テンプレ等を将来）
└── GEMINI3_IMAGE_PROMPTS.md  # 画像生成指示書
```

## 4ステップフロー

1. **Hero** — 「あなたの会社の森を、見つけよう」
2. **会社情報入力** — 会社名・業種・予算・希望地域・森への想い
3. **候補表示** — 全国地図 + 候補3〜5山のカード（CO₂吸収量・クレジット価値）
4. **深掘り** — 氷見市（令和7年度委託事業対象地）の衛星画像 + 林野庁データ
5. **コミット証明書** — 暗号タイムスタンプつきの仮証書

## 技術スタック

- Vanilla HTML / CSS / JS（ビルドステップなし）
- Leaflet（地図）
- ESRI World Imagery（衛星タイル、無料）
- OpenStreetMap（基図、無料）

## 設計の哲学

- **無料データのみ**：Sentinel-1/2、Landsat、林野庁オープンデータ
- **モリアゲのブランドに調和**：Noto Sans JP + M PLUS Rounded 1c + Josefin Sans
- **「精度競争」ではなく「検証可能性 × 普及可能性」**で差別化
