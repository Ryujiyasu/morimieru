# 画像生成・配置の手順

1. Gemini 3 で上記プロンプトを順次実行
2. 生成された画像を `/var/www/morimieru/article/img/` に指定ファイル名で保存
3. 画像最適化（推奨）：jpegoptim または squoosh で 200KB 以下にすると LCP 改善

```bash
sudo mkdir -p /var/www/morimieru/article/img
# 生成画像をアップロード後
cd /var/www/morimieru/article/img
sudo find . -name "*.jpg" -exec jpegoptim --max=85 --strip-all {} \;
```

4. 各記事の `<img>` タグが画像を参照することを確認
5. デプロイ後 Google Search Console に再クロール依頼
